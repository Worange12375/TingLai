# 听籁 SoundVerse · 识别服务依赖

# 安装：pip install -r requirements.txt
#
# ⚠️ 系统级依赖（pip 装不了，必须由系统包管理器提供）：

#      Debian/Ubuntu:  apt-get install -y ffmpeg
#      Dockerfile 里已经装好，裸机部署请手动装。
#
# ⚠️ birdnetlib 会自动拉 tflite-runtime / librosa / numpy / resampy 等；
#      首次运行还会下载 BirdNET 模型（约 50MB）到 ~/.cache 或 site-packages 目录，
#      所以容器首次启动需要能访问外网，且要给足磁盘空间。
